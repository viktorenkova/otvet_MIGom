# Вопрос по лоту

intent: lot transfer pickup inspection refusal penalty

## Ответ

По конкретному лоту укажите номер лота, текущий статус, который вы видите в личном кабинете, и суть вопроса: передача, оплата, осмотр, документы, отказ, штраф или выдача.

Я не подтверждаю адрес, VIN, документы, статус передачи или решение по спору без системных данных. Эти сведения нужно проверять через обращение.
