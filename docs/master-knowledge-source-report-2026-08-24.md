# Отчёт о создании мастер-документа MIGTORG

Дата фиксации: 2026-08-24.

## Результат

Создан `knowledge/MASTER_KNOWLEDGE.md` — единый канонический первоисточник подтверждённых знаний проекта. Он объединяет человекочитаемое описание и машинно-читаемые канонические блоки, из которых публикуются совместимый слой v2, runtime-БЗ v3.1 и answer contracts.

В документ без смысловых изменений перенесены:

- 141 активный сценарий;
- 574 подтверждённых факта;
- утверждённые краткие и подробные ответы, следующие шаги, действия и правила эскалации;
- текстовые сведения об источниках, даты проверки, владельцы проверки и эксперты;
- 3 ранее принятых содержательных пробела знаний;
- 5 неопубликованных кандидатов, ожидающих экспертного решения;
- реестр всех 107 уникальных текстовых описаний источников.

Наследуемая БЗ полностью учтена: в инвентаризации 293 записи, из них 118 мигрированы, 173 объединены с v2 и 2 деактивированы; неразобранных записей нет.

## Обязательные пробелы

До получения подтверждённой актуальной информации нельзя додумывать ответы по трём вопросам:

1. Возможность и порядок скачивания всех фотографий лота одним архивом.
2. Условия, при которых неиспользованный тариф считается истёкшим или «сгоревшим», и основания его восстановления.
3. Единый срок доступа, если пользователь не указал тип тарифа.

Кроме того, зафиксирован системный пробел происхождения данных. У сценариев есть текстовое поле источника, эксперт и дата проверки, но у 574 отдельных фактов нет прямых `evidence_path`, `evidence_sha256` и точной ссылки на место в первичном документе. Поэтому существующую текстовую атрибуцию нельзя выдавать за доказанную связь каждого факта с конкретным файлом.

На 2026-08-24 просрочена повторная проверка пяти сценариев: `bid.not_visible`, `auction.status`, `contract.receive`, `win.next_steps` и `pickup.receive_lot`. Их факты не изменялись без подтверждения; требуется повторное согласование владельцем БЗ и указанными экспертами.

Отдельно перенесена очередь из пяти экспертных задач: полный регламент лояльности, коллизии договорных сроков, последствия отказа от лота, правила штрафа и матрица владельцев/публикации знаний. Эти записи явно обозначены как кандидаты и не включены в опубликованные факты.

## Правило изменения

Канонические данные редактируются только в JSON-блоках мастер-документа. Человекочитаемые разделы и производные файлы создаются командами:

```powershell
python -m backend.tools.master_knowledge render
python -m backend.tools.master_knowledge publish
python -m backend.tools.master_knowledge validate
python -m backend.tools.validate_knowledge_v31 --output reports/knowledge-v31-validation.json
```

Ручное редактирование `knowledge/v2/scenarios.json` и файлов `knowledge/v3_1` не допускается. Проверки блокируют расхождение мастер-документа с опубликованными слоями.
