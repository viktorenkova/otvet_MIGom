# Подготовка этапа 5: новый blind release-gate

Дата фиксации: 24 августа 2026 года.

## Результат инженерной подготовки

Создан fail-closed контур независимой подготовки и заморозки blind-набора. Детерминированный селектор работает с обезличенным support-корпусом, не выбирает формулировки вручную, удаляет точные пересечения с известными regression-корпусами и не публикует фразы в Git. Review-pack записывается только в игнорируемый `.work/stage5-blind-review-pack.json`.

Текущий source SHA-256: `cc853d5ea049e0576cd658114a88c684e0b0454b693aa9a3488385d972ad624c`. В нём 1 023 candidate-сообщения; после фильтрации осталось 922 уникальных пригодных сообщения. Подготовлены 500 одиночных кейсов и 50 реальных пользовательских диалогов (112 ходов), всего 612 записей для разметки. Privacy rejections — 0, точных пересечений с известными regression-корпусами — 0.

Исправлен дефект первоначального отбора диалогов: прежний алгоритм учитывал только сообщения класса `candidate` и удалял одинаковые тексты до группировки, поэтому находил 45 цепочек. Новый алгоритм восстанавливает инициатора обращения по обезличенному `speaker_key`, включает его содержательные реплики разных классов, исключает ответы сотрудников и после этого детерминированно выбирает 50 из 61 пригодного реального диалога.

Freeze-validator проверяет одновременно четыре обязательных условия: 500 одиночных кейсов, 50 диалогов, независимую reviewer attestation и полную утверждённую разметку каждой записи. Тесты подтверждают fail-closed поведение: пакет с 49 диалогами или без независимой attestation не может быть заморожен.

## Незавершённый внешний review-gate

Этап 5 **не завершён и первый blind-прогон не выполнялся**. Количественный data-gate закрыт: есть 500 одиночных кейсов и 50 реальных диалогов. Остаётся независимо разметить 612 записей человеком, который не менял router, retrieval, reranker, answer contracts и matching configs. Автоматическая разметка разработчиком запрещена протоколом.

Для нетехнического исполнителя создана автономная форма `.work/stage5-independent-labeling-form.html`. Она не содержит ответов бота, сохраняет локальный черновик, показывает диалоги по ходам, проверяет обязательные поля и экспортирует совместимый `stage5-blind-reviewed-pack.json`.

После независимой разметки нужно выполнить `python -m backend.tools.freeze_stage5_blind_pack`, закоммитить созданный manifest до первого запуска, затем прогнать пакет текущим локальным HTTP runtime и зафиксировать результат до раскрытия фраз разработчику.

Понятное задание для независимого сотрудника подготовлено отдельно: `docs/stage5-independent-labeling-tz.md`.

## Вклад в итоговую цель

Подготовленный контур не повышает измеренную точность сам по себе, но защищает итоговую цель 8/10 от ложноположительного подтверждения на знакомых или синтетических формулировках. Инженерная часть готова; численное подтверждение на новом blind-корпусе пока отсутствует.
