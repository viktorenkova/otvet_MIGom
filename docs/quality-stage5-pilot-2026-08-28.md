# Сокращённый blind-пилот этапа 5 от 28 августа 2026 года

## Решение владельца проекта

До полного release-gate проводится отдельный сокращённый blind-пилот. Он нужен для первого диагностического запуска и **не заменяет** формальный gate на 500 одиночных обращений, пока критерии основного плана не пересмотрены отдельно.

Утверждённый состав пилота:

- ранее размеченные одиночные обращения после удаления сообщений сотрудников;
- 100 дополнительных одиночных обращений покупателей;
- все 50 реальных пользовательских диалогов — 112 реплик;
- все сохранившиеся экспертные случаи.

## Очистка одиночных обращений

При сопоставлении с обезличенными исходными метаданными инициатором обращения считается автор первого сообщения разговора. В одиночный набор включаются только содержательные сообщения этого инициатора; ответы сотрудников, системные сообщения, контактные данные без вопроса и подтверждения получения исключаются.

Очистка исходного черновика дала следующий результат:

- из 101 утверждённой одиночной записи сохранена 81, исключены 20 ответов сотрудников;
- из 6 одиночных экспертных записей сохранены 2, исключены 4 ответа сотрудников;
- из оставшихся пригодных обращений детерминированно взяты следующие 100 записей со статусом `pending`;
- дополнительно обнаружены 64 неразмеченные одиночные записи сотрудников; они в пилот не включены.

Итоговый одиночный набор содержит 183 записи: 81 утверждённую, 2 экспертные и 100 новых.

## Диалоги и порядок работы

Все 50 диалогов сохранены полностью. Из 112 реплик:

- 107 реплик с полной разметкой по решению владельца проекта переведены в статус `approved`;
- 5 реплик сохранили статус `needs_review` и требуют экспертного решения.

В форме установлен явный порядок:

1. 7 экспертных случаев — 2 одиночных и 5 диалоговых;
2. остальные реплики диалогов;
3. 100 новых одиночных обращений;
4. 81 ранее утверждённое очищенное одиночное обращение.

Всего в пилоте 295 записей. На момент формирования утверждено 188, экспертного решения требуют 7, новой разметки требуют 100.

## Ограничение результата

Результаты пилота можно использовать для первичной диагностики. Если после просмотра его ошибок система будет изменена, использованные 295 записей перестанут быть blind для последующего release-gate. Закрытие этапа 5 и разрешение production по-прежнему требуют либо выполнения исходного gate, либо отдельного заранее зафиксированного изменения статистического протокола.

## Статус с 1 сентября 2026 года

Владелец проекта разрешил использовать текущую утверждённую разметку для улучшения БЗ. На момент решения в полученном черновике утверждена 221 запись: 109 одиночных обращений и 112 реплик всех 50 диалогов; 74 одиночных обращения остаются без разметки.

С этого момента утверждённые 221 записи являются **development-набором**, а не blind-контролем: их формулировки и ожидаемые ответы сопоставлены с БЗ и использованы для расширения retrieval-примеров и очереди экспертных вопросов. Эти записи нельзя учитывать как независимое доказательство качества изменённой на их основе системы. Для итогового release-gate потребуется отдельная неиспользованная контрольная выборка либо заранее утверждённый новый статистический протокол.
